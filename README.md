# Классификация новостных заголовков с помощью BERT

Сравнение трансформерной модели BERT и классических ML-подходов (TF-IDF + Logistic Regression / LinearSVC)
на задаче классификации новостных заголовков по темам.

▶️ **[Открыть блокнот в Google Colab](https://colab.research.google.com/github/rustam4ike/classification_ru_news/blob/main/practice_3.ipynb)**

**Стек:** Python, PyTorch, HuggingFace, Transformers, scikit-learn, pandas, matplotlib, seaborn

## Данные

Использован датасет новостей Lenta.ru `lenta-ru-news.csv`

## Задачи

- Подготовить датасет новостей Lenta.ru
- Дообучить RuBERT (`DeepPavlov/rubert-base-cased`) для классификации заголовков
- Сравнить трансформер с классическими ML-моделями на TF-IDF
- Оценить качество по Accuracy и F1-score (weighted), построить матрицы ошибок

## Реализация

1. Из `lenta-ru-news.csv` берутся основные поля, отбираются 10 самых частых тем по 7000 примеров на класс
2. Разбивка выборок проходит в соотношении 80% train / 10% validation / 10% test
3. Выполняется токенизация RuBERT и создаются три датасета
4. Проводится настройка гиперпараметров RuBERT с помощью функции `TrainingArguments`
5. Модель дообучается на тренировочной выборке
6. На тесте оценивается качество, строится матрица ошибок
7. Результаты RuBERT сравниваются с классическими ML-моделями

## Результаты

- RuBERT после файн-тюнинга превосходит классические модели по Accuracy и F1 на 11%
- Матрицы ошибок показывают, между какими темами модели путаются чаще всего
- TF-IDF + Logistic Regression / LinearSVC дают хороший baseline при значительно меньших затратах на обучение
